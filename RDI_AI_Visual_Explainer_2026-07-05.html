Flow · the attachment fix

Attachments that survive follow-ups

The headline fix: uploaded files are now persisted and re-injected on every later turn — so follow-up questions still "see" the document.

What changed — before → after

A full audit found 22 defects plus the attachment/context and PPTX-quality issues. All were fixed and verified.

⚠ Before

  • Attachments ignored on follow-ups — files weren't stored in history, so later turns got generic answers
  • SSO accepted unverified tokens — anyone could forge any user
  • Random JWT secret — prod (4 workers) stuck users in a login loop
  • Codex models secretly ran GPT-4o
  • PDF crashed on bullets, dashes, ellipses
  • Claude/Bedrock agent mode crashed on first tool call
  • Most models billed $0 — pricing keys never matched
  • Generic PPTX — 4:3, one template, bullet walls

✓ After

  • Attachments persisted + re-injected every turn and after reload (verified)
  • SSO cryptographically verified against Azure JWKS (signature, audience, issuer, expiry)
  • Persistent JWT secret — restart-safe, multi-worker-safe
  • Codex runs for real via the Responses API
  • PDF safe — Unicode transliteration + cursor fix (verified renders)
  • Agent works on every provider — tool-call formats unified
  • Accurate cost tracking — keys match real model IDs (verified)
  • Designed decks — 16:9, 7 layouts, notes, slide numbers
